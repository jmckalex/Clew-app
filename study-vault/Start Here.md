# Start Here

This is the **study vault** — a worked example of Clew's database
features, staged as one academic's term. Everything in it is plain
Markdown; and yet, taken together, it runs like an app.

Press **⌘E** to read this note rendered, then follow the thread:

- [[Why a Writable Vault]] — *read this first*: what these features are
  actually for.
- [[Dashboard]] — the whole term at a glance, queried live from the
  files around it.
- [[Pipeline]] — the papers-in-progress kanban. **Drag a card** to
  another column, then open that paper's note: its frontmatter changed.
- [[Reading List]] — an editable table. **Click a rating**, type a new
  one, press Enter: the book's note now says so.
- [[Marking]] — a marking tracker built from three frontmatter keys.
- [[Errands]] — tasks scattered anywhere, gathered into one list that
  writes back when you tick things off.

Nothing here is special. There is no database file, no app state — only
the notes in this folder, with a few lines of frontmatter each. Delete
Clew tomorrow and every fact survives as text.
