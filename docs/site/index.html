Clew

A thread through your notes.

An open-source, Obsidian-style note app whose reading mode is a real typesetting engine. Plain-text vaults, wikilinks, and canvases that Obsidian can still open — with LaTeX math, citations, diagrams, interactive maps, and a programmable core that Obsidian can't match.

GPL-3.0 macOS · Windows · Linux Obsidian-compatible vaults No accounts, no cloud, no lock-in

Reading mode is a typesetting engine

Clew renders notes with jmarkdown, an engine built for academic writing: the same source file compiles to HTML in the app and to LaTeX/PDF for print. Not a preview approximation — the real thing.

Math, theorems, citations, diagrams

  • LaTeX math via MathJax — inline, display, AMS numbering and cross-references
  • Theorem environments — theorem, lemma, proof, numbered and referenceable
  • Citations from BibTeX — \cite{lewis1969} with real bibliography styles, and cite-key autocompletion in the editor
  • Diagrams — mermaid fences, TikZ, MetaPost
  • Footnotes, alerts, tables, tags, GitHub-style callouts

Export any note to HTML, LaTeX, or PDF from the File menu — same source, print-grade output.

A dialect worth learning — or turning off

The jmarkdown dialect gives dedicated syntax to the things academics actually write: /italics/, *strong*, ==highlights==, TeX-style sub/superscripts, inline footnotes, alignment blocks.

Prefer standard Markdown? One per-vault switch reverts the inline syntax to ordinary *em*/**strong** — and because jmarkdown is a superset of Markdown, any existing vault renders as its author intended, plus everything above.

A canvas that draws

An infinite board for notes, files, web pages, and thought — with the drawing tools Obsidian's canvas never got.

Excalidraw looks, flowchart brains

  • Ink and shapes with three sloppiness levels, dashed/dotted strokes, hachure fills, opacity, and standalone text in four typefaces
  • Flowchart node styles — pill, diamond, parallelogram, predefined process — plus edge routing (curved, straight, square), arrowheads both ways, z-order control
  • Live note embeds — actual rendered notes on the canvas, math and all; web pages; PDFs; media
  • Portals — drop a canvas onto a canvas and see a live miniature
  • PNG export of the drawing layer, and live read-only canvas embeds inside notes

Files are standard JSON Canvas — Obsidian opens them; Clew's extras ride in a key other apps ignore.

Maps, memory, and territory

A ```leaflet fence renders an interactive map — most of the beloved Obsidian Leaflet plugin's surface, built in.

Pins, tracks, and a day of photos

  • Markers with popups and wikilinks; markers gathered from note frontmatter across files, folders, or tags
  • GeoJSON regions, GPX tracks, circle overlays, distance measuring
  • Six tile styles (the default is CARTO's Google-Maps-like Voyager) or any custom tile server; offline image-based maps for floor plans and fantasy worlds
  • Photo maps: point photos: at a vault folder and every geotagged photo becomes a pin — thumbnail popup, capture time, and a link that opens or creates a note about it. iPhone HEIC converts to JPEG automatically.

A diary with views

One log or many files — your choice

  • A calendar in the sidebar: dots mark days with entries, click any day to open or create it
  • Keep per-day files or one single log with dated sections
  • Composed views: today, this week, this month, any interval, or the whole diary — rendered as one continuous document
  • Daily-note templates with date substitution

And the whole vault as a graph

Backlinks, outgoing links, unlinked mentions, tags, an outline panel, full-text search — and a force-directed graph of the whole vault or the local neighborhood of the current note.

Symlinks are fully supported (cycle-safe), so vaults can weave in folders that live elsewhere — something Obsidian never allowed.

Programmable to the bone

Two scripting stories, both traveling with the vault — because Clew is open source, extension isn't a business model, it's a folder.

The Note API

A <script> in a rendered note gets a window.clew API: open notes, search, read and write files and frontmatter, run commands, and share state in a clewdata.json that syncs with the vault. Notes become small apps — habit trackers, dashboards, even games.

Vault plugins

A folder under .clew/plugins/ extends Clew at three seams: engine (new syntax — fences, directives), preview (decorate rendered notes), and app (commands, vault IO, notices, against a small versioned API). Off until enabled, per vault. 

clew.commands.register({
  id: 'count',
  name: 'Word count',
  run: async () => {
    const p = clew.workspace.activePath();
    const t = await clew.vault.read(p);
    clew.ui.notice(t.split(/\s+/).length + ' words');
  },
});

Everything else you'd expect

Command palette, editable hotkeys, native menus, tabs and splits with per-tab history, pinned tabs, multiple windows (one vault each), properties panel, bookmarks, attachment paste, vault-wide rename with link rewriting, dark and light themes, CSS snippets.

Your files stay yours

A vault is a folder of Markdown. Clew never touches .obsidian/, keeps [[wikilinks]] Obsidian-shaped, and stores its own state in a separate .clew/ folder — open the same vault in both apps, today. No accounts, no telemetry, no sync service required: it's your disk, your git, your call.

Getting started

  1. Build from source (Node 20+): 
    git clone <repository-url> clew && cd clew
npm install
npm run dev        # develop
npm run package    # build the app for your platform
  2. Open a vault — any folder of Markdown files, including an existing Obsidian vault.
  3. Read the guide — the bundled demo-vault/ is Clew's documentation written in Clew: every guide note exercises the features it documents.
