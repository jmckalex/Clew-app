# Daily Notes and Templates

**⌘⇧D** opens today's daily note, creating it if needed — named by the
date format and folder in Settings (default `Daily/YYYY-MM-DD.md`). Point
"Template note" at any note to seed new daily notes from it.

**⌘⌥T** inserts a template at the cursor, picked from the templates
folder (default `Templates/` — see [[Meeting]] for an example).
Placeholders are substituted on insert:

- `{{date}}` and `{{date:YYYY-MM-DD}}`
- `{{time}}` and `{{time:HH:mm}}`
- `{{title}}` — the current note's name

See also: [[Settings and Hotkeys]].
